# StackSaver AI

StackSaver AI is a free AI spend audit tool for startup founders and engineering managers. It helps teams review AI tool subscriptions and API spend, estimate savings, and capture optimization opportunities.

Live URL: https://stack-saver-ai.vercel.app/
